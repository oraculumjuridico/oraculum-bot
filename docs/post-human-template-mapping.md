# Mapeamento do template pós-atendimento

O catálogo interno `casoAtualizacao` aponta para o template Meta aprovado
`caso_atualizacao_v3`, idioma `pt_BR`, categoria Utilidade.

Contrato confirmado do template `caso_atualizacao_v3`:

- Nome: `caso_atualizacao_v3`
- Idioma: `pt_BR`
- Status: `APPROVED`
- Categoria: `UTILITY`
- Componentes: `HEADER` (IMAGE), `BODY` (1 variável), `FOOTER`
- Botões: nenhum

Variável de imagem:

- Canônica: `POST_HUMAN_TEMPLATE_IMAGE_URL`
- Alias legado: `WHATSAPP_TEMPLATE_CASO_ATUALIZACAO_IMAGEM_URL`

A URL pública da imagem é obrigatória para o envio real fora da janela de
24h. Dentro da janela, o envio pode prosseguir sem imagem, mas a validação
do contrato continua esperando o componente `HEADER`.
